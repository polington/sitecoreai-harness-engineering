## 0. Pre-Requisites — Supporting Template (PromoCard)

> **Complete this entire section before executing Section 1.** The PromoCardGrid
> datasource template (created in Section 1) includes a Multilist field whose Source
> points to PromoCard items. The PromoCard template must exist before the Multilist Source
> can be configured in Section 2.2.

### 0.1 Create the PromoCard Template

Create the template used by individual promo card data source items.

1. In **Content Editor**, navigate to:
   `/sitecore/templates/Project/harness-engineering/`

2. Right-click the `harness-engineering` folder and insert a new **Template** item named
   `PromoCard`.

3. On the template, open the template builder. Create a template section named `Data`.

4. Add the following fields to the `Data` section:

   | Field Name | Field Type | Notes |
   |------------|------------|-------|
   | `Image` | Image | Card image rendered at the top of the card with 16:9 aspect ratio. Author sets alt text via the image field's alt property. |
   | `Title` | Single-Line Text | Card heading rendered as an `<h3>` element. |
   | `Description` | Multi-Line Text | Card body text rendered below the title. |
   | `Link` | General Link | Optional CTA link. When empty, no CTA element is rendered. |

   > **Field names are exact** — they must match the TypeScript field names in
   > `promoCardGridTypes.ts` character-for-character (case included). Mismatches cause
   > the component to receive `undefined` field values and render nothing.

5. Save the template.

The PromoCard template path is:
`/sitecore/templates/Project/harness-engineering/PromoCard`

### 0.2 Create the PromoCardGrid Data Folder

1. Navigate to the site's Data folder:
   `/sitecore/content/harness-engineering/harness-engineering/Data/`

2. Right-click the `Data` folder and insert a new **Folder** item named `PromoCardGrid`.

   **Path after creation:**
   `/sitecore/content/harness-engineering/harness-engineering/Data/PromoCardGrid`

### 0.3 Create the Cards Folder

1. Navigate to:
   `/sitecore/content/harness-engineering/harness-engineering/Data/PromoCardGrid/`

2. Right-click the `PromoCardGrid` folder and insert a new **Folder** item named `Cards`.

   **Path after creation:**
   `/sitecore/content/harness-engineering/harness-engineering/Data/PromoCardGrid/Cards`

> This folder will hold individual PromoCard data source items. The Multilist Source on

## 1. Create Rendering and Datasource Template

Follow the **Sitecore Accelerate Cookbook** recipe for creating new components.

**Recipe source (canonical):**
`https://developers.sitecore.com/learn/accelerate/xm-cloud/implementation/developer-experience/creating-new-components`

> ⚠️ **Before executing this section,** visit the
> [Sitecore Accelerate Cookbook recipe](https://developers.sitecore.com/learn/accelerate/xm-cloud/implementation/developer-experience/creating-new-components)
> and verify whether the steps listed here match the current published version.
> If the live recipe differs, follow the published recipe over the steps in this guide.

> ⚠️ **Fallback in use:** The Accelerate Cookbook URL was not reachable at guide-generation
> time. The steps below use the **Clone Rendering SPE script** fallback, which the
> Cookbook recipe prescribes as the standard mechanism for creating new headless renderings
> with datasource templates. If the recipe URL becomes accessible, re-read it and verify
> these steps match. The URL is the authoritative source of truth.

### Steps (Clone Rendering SPE script — fallback)

1. In Content Editor, navigate to an existing Json Rendering to use as the clone source.
   Use the Header rendering created by T001:
   `/sitecore/layout/Renderings/Project/harness-engineering/Header`
   (Any other Json Rendering in the same folder is equally acceptable as the source.)

2. Right-click the source rendering item and select **Scripts > Clone Rendering**.

3. In the Clone Rendering dialog, set the following values:

   | Dialog field | Value |
   |---|---|
   | **New rendering name** | `PromoCardGrid` |
   | **Rendering destination** | `/sitecore/layout/Renderings/Project/harness-engineering` |
   | **Datasource template** | **Create Copy** ← **must change from the default (Inheritance)** |
   | **Datasource template destination** | `/sitecore/templates/Project/harness-engineering` |
   | **Rendering parameters** | **Create Copy** ← **must change from the default (Inheritance)** |

   > **Important:** Both the **Datasource template** and **Rendering parameters** options
   > default to **Inheritance**. You **must** change both to **Create Copy**. Leaving
   > either on Inheritance causes the new rendering to share its template with the source
   > rendering, which creates field conflicts that are difficult to debug.

4. Click **Proceed**.

5. Confirm that the script reports success and that two new items have been created:
   - Rendering: `/sitecore/layout/Renderings/Project/harness-engineering/PromoCardGrid`
   - Datasource template: `/sitecore/templates/Project/harness-engineering/PromoCardGrid`

Proceed to Section 2 to update both generated items with the correct values for this
component.

## 2. Configure Generated Items

Update the rendering item and datasource template that the Clone Rendering script
created. The script copies fields from the source rendering — the steps below correct
them for the PromoCardGrid component.

### 2.1 Update the Rendering Item

**Item path:**
`/sitecore/layout/Renderings/Project/harness-engineering/PromoCardGrid`

Set or verify the following field values:

| Field | Required Value | Notes |
|-------|----------------|-------|
| Component Name | `PromoCardGrid` | Must exactly match the component map key. A mismatch causes the component to render blank. |
| Data Source Template | `/sitecore/templates/Project/harness-engineering/PromoCardGrid` | Full path to the PromoCardGrid datasource template (section 2.2). |
| Data Source Location | `query:$site/*[@@name='Data']/PromoCardGrid/*[@@templatename='PromoCardGrid']` | Returns all items based on the `PromoCardGrid` template inside the `PromoCardGrid` subfolder of the site's `Data` folder. ⚠️ Once the PromoCardGrid datasource template has been created, replace `@@templatename='PromoCardGrid'` with `@@templateid='{GUID}'` using the template's actual item GUID — `@@templateid` is the production-safe form and avoids ambiguity. |
| Rendering Type | `JavaScript` | Should already be set correctly by the script; verify. |

> **Critical:** The `Component Name` field value must be exactly `PromoCardGrid` — this is
> the key registered in the component map by `PromoCardGrid.tsx`. Any capitalisation or
> spelling difference will cause the rendering to display blank in the browser.

### 2.2 Update the Datasource Template

**Template path:**
`/sitecore/templates/Project/harness-engineering/PromoCardGrid`

The script clones fields from the source rendering's datasource template. Remove all
cloned fields that are not listed below, then add or rename fields to match the
implementation exactly.

**Steps:**

1. In Content Editor, navigate to:
   `/sitecore/templates/Project/harness-engineering/PromoCardGrid`

2. Click **Builder** in the top ribbon.

3. Delete all field sections and fields that were cloned from the source rendering's
   template. The final template should contain only a single section and the one field
   listed below.

4. Create a template section named **`Promo Card Grid Content`**.

5. Inside the `Promo Card Grid Content` section, add the following field:

   | Field Name | Field Type | Notes |
   |------------|------------|-------|
   | `Cards` | Multilist | Multi-value field referencing PromoCard items. Set Source (see step 6). |

   > **Field name is exact** — it must match the TypeScript field name `Cards` in
   > `promoCardGridTypes.ts` character-for-character (case included). A mismatch causes
   > the component to receive `undefined` for the field and render nothing (empty state).

6. Set the **Source** field on the `Cards` Multilist field to:

   ```
   /sitecore/content/harness-engineering/harness-engineering/Data/PromoCardGrid/Cards
   ```

   > This displays all children of the Cards folder (created in section 0.3) as
   > selectable values in the Multilist picker. Authors will create PromoCard items
   > inside this folder and then reference them from the grid's Cards field.

7. Save the template (`Ctrl+S`).

**Base templates:** Retain `Standard template` as the base. Remove any source-rendering-
specific base templates if present.
