# Contributing

This repository is a **demonstration project** accompanying a conference presentation on AI-assisted feature engineering with SitecoreAI.

## Scope

This project is published as a reference implementation. It is not actively seeking feature contributions, but bug fixes, documentation improvements, and suggestions are welcome.

## Reporting Issues

If you find a problem or have a suggestion, please [open an issue](https://github.com/robearlam/sitecoreai-harness-engineering/issues).

## Pull Requests

If you'd like to submit a fix:

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes
4. Ensure tests pass (`npm test` from `src/headapps/rob-harness-engineering/`)
5. Ensure linting passes (`npm run lint`)
6. Submit a pull request

## Code of Conduct

Be respectful and constructive. This is a learning resource shared with the community.
